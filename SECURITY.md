# Security Policy

## Supported Versions

This is a sample/template project rather than a versioned library — only the latest code on `main` is supported.

## Reporting a Vulnerability

If you find a security issue in this repo, please **don't open a public issue**. Instead, use GitHub's private reporting:

1. Go to the [Security tab](../../security) of this repository.
2. Click **"Report a vulnerability"** to open a private advisory.

Alternatively, reach out directly via [GitHub](https://github.com/Nerojust).

You should get a response within a few days. This is a template app with no real backend or user data (it talks to the public GitHub API only), so the practical impact of most findings will be limited — but pattern-level issues (e.g. something the app demonstrates incorrectly as a "secure" or "correct" pattern) are very much worth reporting, since the whole point of this repo is showing those patterns correctly for others to build on.
